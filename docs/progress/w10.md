# W10: SQL execution policy

Scheduled November 23, 2026. Implemented November 25 as catch-up. Tracks #18 in draft PR #17, which is stacked on P04.

The internal worker can run an analytical SELECT over the current import. A small parser checks the query before container creation and again against the actual table inside the container. The compiler binds literals as parameters and uses a fixed relation. See [supported SQL and limits](../sql-policy.md).

The tests verify an aggregate against known data, missing-value filters, denial before launch, and execution and truncation inside Docker. No HTTP endpoint or model tool was added. W11 will connect typed tools and model adapters.
